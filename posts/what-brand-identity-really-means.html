What Brand identity really means

Diop Makhtar

20 hours ago·2 min read

Brand identy is broadly misunderstood. These two words brand and indentity are not compounded words each one being here to reinforce the global meaning but it’s a mapping process that is involved. It is a map function like this brand -> Identity or the inverse function. That’s this map function that seth godin, the thought leader and author of permission marketing, illustrates with this sentence people like us do things like this. This sentence clearly defines what the audience of a brand is. It is people like us.(indentity) A mean for identifying ourself as part of a tribe that care about a particular thing, or does a particular thing. This particular thing is the medium of the brand or the brand raisin d’etre. So we have a clear process for creating successful brands. This process don’t and never start with a logo, a business plan, a great website, ourselves or our identity but it starts with people, with others who happen to be the answer of the first question we should ask ourselves as brand creators or marketers, who is it for? After answering this question, we get our minimal audience this small set of persons who define themselves as part of a tribe by saying people like us. The next part of the brand creation process is to answer to the question what is it for? This second question is for defining the second part of the sentence which is do things like this. This part in fact the first element of the map function I stayed at the beging. This map brand -> identity. So branding is a backward process we start from the end Identity and hit the end Brand. Inverting this function is what brand creators try everyday.

This word is core process in how our brain work and it is key tool in science like mathematics and physics if you master this process you will see differently and better.
