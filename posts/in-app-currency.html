In-app currency

Diop Makhtar

·Oct 14, 2020

We could create this in-app currency that you could get by engaging with our network and this currency could be already better than all kinds of currency you use today. But we just decided to not use it now because we just see something that it shares with currency systems. We would it not only to be better what it already is but we want it absolutely different and useful for people. We still cannot make others than developers benefit from this. Attention is a currency thank you for giving me attention.
