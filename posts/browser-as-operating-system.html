Browser as operating system

Diop Papa Makhtar

·
·
Mar 6, 2021

--

In 2010 I saw that browsers were going to disrupt operating systems like mac osx, windows and Linux. I saw that things to do with computers was going to be more and more done inside browsers and there was an opportunity to build a simple system that could allow a computer to just run and render a browser like chrome, internet explorer or firefox as the operating system and more I thought that the employees' computer should have been able to host apart from this browser an agent that could allow the execution of production tasks that use to run On dedicated servers. Of course, it was a major architectural shift and a cloud solution before the cloud appeared to be a trending solution. I failed to pitch this solution to French companies that are active in the computer services industry. Osiatis was one of them, neurons also. At that time I was a homeless entrepreneur without a computer and was mainly reading books and working on this tech idea by monopolising one computer of this library where I only could be in a hot space that protects me from the hard winter and the summer I was also there. I was not able to go far from the dev process because I was not able to install anything on the computer I was using. Now more than ten years after I am here in my born country with my smartphone, two mac books and a Pc and all of the ideas I was going into 10 years ago still matter. There will be a lot of things to do with browsers, c++, python, java, javascript and rust not just browsing
