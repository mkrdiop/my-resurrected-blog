Sensors like thermometers in smartphones

Diop Makhtar

·Just now

There is not a thermometer inside smartphone and we keep talking about climate change.

The system now just gather data to server giving their location for the server to send the local metro.

What if all the smartphones of the world had meteo sensors that give data to a system that aggregate them and give us insight about climate and pollution level.

It is always better when it is done with others but don’t wait for consensus for acting!
