Economics of search engines and page loading time

An AI system that optimizes search engine spiders processing time

Diop Makhtar

Dec 26, 2021·4 min read

I have been writing about core web vitals and how it was important for users to have a faster web experience in terms of page load and web assets delivery. But I hope that like me you also have spotted the fact that improvement of page loading time microseconds to a second is also beneficial to search engines startups and companies because their search spiders are crawling the internet by accessing billions of webpages and loading their content for analysis of ranking. Then it takes to each webpage to be loaded is an idle time for these search engine spiders waiting for the content of the page to be accessible and this time is for the search engine operations a waste of time and can cost millions of dollars if the loading times of billions of webpages are compounded. This is for search engines an extra cost that they would avoid and improvement of a microsecond of loading time by every webpage will lead to search engines saving a huge amount of networking and computation cost then dollars by the same token.

In my point of view, core web vitals consideration by search engines is not only beneficial to end users but also to these same search engines that will, in turn, save money by processing daily webpages. less loading time means simply less money to spend and for estimating the amount of money that will be saved we could use the pricing of serverless cloud because these cloud computation services value computation in second and even microseconds.

I am even imagining more cost-conscious search engines systems doing cost optimization by clearly trying to understand the functioning of each webpage and distinguishing clearly the process that has an effect on the content that is presented to the user and those that don't. For example with third-party services, websites can now embed commenting systems, chatbots, and popup systems. You could remark that all these services are not so important to the eyes of a search engine but their implementation relies on JS scripts that are embedded on the webpage. A cost-conscious search engine system could simply have a built-in system that will prevent the loading of such third-party scripts that don’t affect the content that is about to be extracted and save processing time. For example, CSS assets aren’t so important for a search engine spider because they are implemented only for visual aspects even if the visual aspect can be a content structure like when we make bold a word we are highlighting its importance and it can be considered as a structural meaning like HTML tags but if you take the example of third-party services like intercom and other chatbots they didn’t participate in the understanding of the structure of the information that the search engine spider is trying to get. Such kinds of third-party services that are often based on javascript are skipped by a cost-conscious search engine webpage processing system.

A search engine spider is like a user in front of her browser but here the visual aspect and interactivity are taken into consideration only if they play a role in the meaning and understanding of the content to be indexed. You see that building a search engines spiders is not like building a webpage scrapper because the scale at which the spiders will be processing makes optimization an important part because that’s millions of dollars of cost-saving opportunities that are engaged.

Taking all these thoughts into consideration makes the understanding of webpage processing important on a webpage-by webpage basis because that’s this understanding that will let the spiders of the search engines system to know what web asset to care about. Given the number of web pages that are crowding the internet each one to be processed by a search engine doing this analysis like what I was doing in this article is not scalable because it is done by humans like shown in the following screenshot.

An AI system that could process a webpage, study its loading process and structure, and all the web assets involved in the processing of the content in order to provide indications to spiders about what to process and how is a really good search engine solution that search engine like google will want to leverage and the many search engine startups like Duckduckgo, Neva and others is a signal that if you work in such kind of AI system and go deep into the economical benefits they provide to search engines owner could be a very successful entrepreneurial path for those interested in AI.
