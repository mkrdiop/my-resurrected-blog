Up to Bottom Software development

Diop Makhtar

Just now·1 min read

Software should be developed from up to bottom, frontend to the backend. Your database technology, your webserver technologies don’t matter before you design and develop the things that the users will see and engage with that’s the most important part of your software project. history has shown that the software companies using this methodology build better software faster and have better user experience because before choosing the backend technology and stack to implement those companies focus first on the features that the users see and keep getting insights to make them better until the end of the project. it is also good to know that managing software project to ship on the right date is a complex thing and some probability theory may help predict the outcome of the project and being agile can help get things done. As a software company, you should care about this.
