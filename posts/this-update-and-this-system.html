This update and this system

Diop Makhtar

3 days ago·2 min read

Each time the state of the computer of a member of a team, company has changed the snapshot of the new operating system state should be stored somewhere because this is the one that will be used to test the next updates or software to be installed in the computer in production. Once the test leads to success in this virtual machine instantiated for test purpose the updates can be ready for deployment in the production infrastructure.

Sometimes updates lead systems to unexpected behaviors. This just happened to me two days after updating my operating system for installing this new shell tool that allows me to work both in Dos command line, PowerShell, and Linux shell bash. it was a very good environment for me when I got everything working for me to work in both Linux and windows without dealing with a virtual machine software like VMware but all of a sudden my computer started refreshing the explorer process of the operating system almost every second and closing the opened folders. I was not able to work with it and I just tried some search to fix it. I went to google and StackOverflow after I suspected the update to be accountable for this behavior. I don't know if that’s in google, StackOverflow I discovered the solution or if I got it by myself but once I removed the update, my computer started working correctly. If such was the case in the test virtual machine, this update would never be deployed on my computer and I would never deal with all this time for deploying, searching, and deploying a backup system state. I really need this update and this new shell tool so I must figure out how to get it working and this system I am describing here is also a very interesting system to build so go build it.

and don't forget that a google core web vital update is maybe coming and it could bring some changes in how websites are ranked in search results because what will matter will be if the visitor's experiences of visitors they send you is the best one. I guess that’s what always mattered for google and this will be another improvement in this direction.
